# ChatGPT Project 设置

1. 新建 ChatGPT Project，建议名称：`FloraLab｜花艺创作空间`。
2. 打开 Project Instructions，把 `project-kit/PROJECT_SYSTEM_PROMPT.md` 全文复制进去。
3. 将 `project-kit/` 中除 `PROJECT_SYSTEM_PROMPT.md` 外的资料文件上传到 Project。
4. 以后直接自然聊天即可，不需要记命令或遵循固定问答流程。

这套 Project Kit 有意只固定共享背景、事实边界和设计气质，不规定模型必须先问什么、必须给几个方案、必须按什么模板输出。目的在于保留模型本身的判断、视觉、研究和创造能力。
