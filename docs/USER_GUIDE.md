# FloraLab 项目使用说明

适用于 Studio 1.7.0。正式入口：[打开 FloraLab Studio](https://fengzide86.github.io/floralab/)。手机打开右上角“菜单 → 使用说明”，电脑可直接点顶部“使用说明”。

## 先理解这个项目怎么配合

FloraLab 帮你把一个想法变成可讨论、可核对、可制作、可复盘的作品。

| 在哪里 | 用来做什么 | 得到什么 |
| --- | --- | --- |
| ChatGPT 中的 FloraLab 创作空间 | 讨论灵感、分析参考图、探索风格、生成效果图、看制作照片 | 设计方向、视觉稿和修改建议 |
| FloraLab Studio 网页 | 记录材料、颜色、数量、预算、结构、制作消耗和成品 | 一件有明确事实和记录的作品 |
| .floralab 文件 | 导出、交接、备份、换设备后导入 | 当前作品的结构化档案；“导出设计与图片”还带上图片 |

两边需要你交接文件和图片，不会自动同步。网页里的“创作空间”按钮目前提供交接提示或复制摘要，不会自动打开你的 ChatGPT Project，也不会把作品自动上传过去。

## 第一次使用：先走完一件小作品

可以从“做一件白绿桌花，不要玫瑰，想要自然、有空隙”开始。先核对一份方案，选定方向，再看材料和摆放。制作时记录用量，最后添加实拍照片并导出文件。没有明确的花材清单也能开始，但生成结果需要你核对。

你也可以先在创作空间发参考图、描述送给谁、放在哪里、想表达什么；方向清楚后，再进入 Studio 建立材料和结构档案。不要为了走流程而把已经确定的作品重新设计一次。

## 1. 新建或接着已有作品

新作品：在首页点“开始一件作品”，填写想法。预算、形式、颜色和已有材料在可展开的补充条件中。已有材料尽量写明确，例如“8 枝白玫瑰”；没有预算可以留空。

点“整理想法，查看方案”后，先看原文和识别结果。当前网页采用有限规则识别，不是完整的对话式 AI；复杂气质、未收录材料和特殊构图不保证正确理解。

写到一半也可以离开：输入会自动保存成一份本机草稿，首页点“继续草稿”接着写；“另起一个想法”会先确认再清除草稿。生成并保存作品后，这份草稿会清除。草稿暂不跨设备同步，保存失败时页面会明确提示，请先复制文字。

浏览器的后退、前进可在工作区之间往返；刷新会回到同一作品和标签。材料详情也可以后退回列表。地址仅帮助定位当前设备里的内容，不会把作品上传给别人；换设备仍需导出、导入 .floralab 文件。

已有作品：在首页打开本机作品接着做；有 .floralab 文件时使用首页导入。导入会新建一份独立作品，避免覆盖已有内容。

## 2. 比较方向并选定一份

进入“想法与方案 → 比较方向”，先预览变化，喜欢再保存为备选。原方案仍会保留。选择准备实际制作的那份，点“选为制作方案”。

“保持不变”约束的是自动生成备选方向时允许改变的内容。手动修改材料、数量或点位会更新当前方案。想保留旧状态，可先导出文件，或之后到“修改与恢复”查看快照。

## 3. 核对材料和采购

进入“材料与准备 → 材料清单”，核对材料种类、颜色、数量、已有数量和单价。网页据此计算还需买多少。

空白单价表示待询价，不等于免费。参考价不能当作真实采购报价；按你实际购买的价格更新。材料替换、数量变化后，重新检查采购缺口和摆放。

需要采购时复制清单或打印。材料库可辅助核对资料，供水、承重、宠物接触、运输和季节供应仍需按实际环境确认。

## 4. 想先看效果，怎么与创作空间交接

在 Studio 顶部点“导出设计与图片”，把最新 .floralab 文件提供给创作空间，也可以复制效果图交接说明。可以这样提出要求：

> 请按这个当前版本做效果图，保持材料种类、颜色、数量、花器、固定结构和主要摆放关系。如果发现不合理之处，先指出，不要自行替换材料。

生成的效果图需要在 Studio 的“想法与方案 → 效果图”添加回这件作品。网页目前不直接调用 AI 生图。

如果讨论后决定改材料或结构，先更新 Studio 的对应事实，再导出最新版本继续。旧效果图在事实变化后会提示待核对。效果图用于看成品感觉；逐枝数量和施工关系以清单与施工图为依据。

## 5. 检查摆放与空间

编辑入口是“动手制作 → 摆放施工图”。总览示意、效果图照片和制作步骤配图主要用于查看。

先从“选择材料点位”选编号，或轻点花头圆点，再拖动。手机在图外滑动页面。不方便拖时用空间按钮，选择每次 1 或 5 cm，向左、向右、靠前、靠后、升高或降低。

| 视图 | 在图上拖动会调整什么 |
| --- | --- |
| 正面、背面 | 左右与高度；背面左右方向相反 |
| 左侧、右侧 | 前后与高度；右侧的屏幕水平方向与左侧相反 |
| 俯视 | 左右与前后 |

空间按钮始终按作品本身的方向计算。原点在花器底部中心，x 向右、y 向前、z 向上。点位锁定时先解锁；移动到尺寸边界会停止。要准确输入数值，可展开“精细调整”。

这里移动的是花头点位，固定点不随它移动，也不支持像 3D 软件那样旋转整个场景。移动不改变材料数量；复制或删除点位会改变数量，因此有确认提示。施工图不代表毫米级精度。

## 6. 开始制作并记录用量

准备好后进入“动手制作 → 制作步骤”，勾选工具、材料和供水等准备项。每做一步，记录实际已用和损耗；这些是实际制作记录，不要为了符合计划而填假数据。

超用时会显示缺口。误填可撤销上一次用料记录。最后点“完成检查，记录成品”，进入成品页。

## 7. 留下成品与复盘

在“成品与记录”添加实拍照片，填写实际难度、耗时、遇到的问题和下次想改的地方，再保存成品记录。完成后可以标记作品已完成。

有添加效果图和成品照片时，可并排比较轮廓、色彩、层次、结构与材料差异。也可以把制作照片和当前 .floralab 文件一起带回创作空间，讨论重心、朝向、拥挤、供水或运输问题。

## 8. 保存、换设备和下次继续

作品和图片保存在当前设备的当前浏览器中，没有账号云同步。关闭页面前注意保存状态；“已保存在本机”表示本次保存成功，本机快照仍不是云端备份。

重要节点建议导出 .floralab 文件留存。选择“导出设计与图片”会带上作品图片；“仅导出材料与结构”不含图片。换手机、换浏览器或准备清理网站数据前，先导出，再在新环境首页导入。

下次在同一浏览器打开首页，从已有作品继续。误改时到“成品与记录 → 修改与恢复”，先预览再恢复；恢复前的当前状态也会另存快照。

## 常见疑问

- **为什么方案不完全符合我那句话？** 当前规则识别有范围限制。先核对识别结果，复杂意图在创作空间讨论，再把确定事实更新回 Studio。
- **为什么图片不能直接拖？** 照片与示意图主要用于查看；位置编辑在“摆放施工图”。
- **为什么点位不动？** 检查是否锁定、是否在尺寸边界；密集点位用列表选择，再用空间按钮调整。
- **为什么另一台手机没有作品？** 本机保存不等于同步。用导出、传输文件、导入完成交接。
- **升级后按钮不响应？** 先复制尚未提交的文字，联网刷新一次。不要为了更新版本清除网站数据。
- **保存失败怎么办？** 保留页面，尝试导出当前内容，确认备份可用后再处理浏览器存储问题。

最关键的习惯：每次跨创作空间、Studio 或设备继续工作，都交接最新文件；已经确定的材料和结构，以最新版本为准。

## 多个标签页同时编辑

如果另一个标签页已保存新修改，当前旧页面会阻止覆盖并显示冲突提示。先导出当前未保存的修改，再重新打开作品读取最新版本。切换工作区不会覆盖材料或结构。

成品页的“标记作品已完成”会一并保存当前填写的耗时、问题和备注；也可以先单独保存成品记录。
