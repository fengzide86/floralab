# FloraLab 1.1.1 视觉对标｜2026

这轮不是照搬某个产品，而是提炼当下成熟产品在“专业工具 + 内容优先 + 跨设备”上的共同方向，再筛选适合 FloraLab 的部分。

## 参考对象

### Linear 2026 UI refresh
重点：更安静、更一致的标题/导航/视图控制；弱化外围导航，让主内容更突出；提高信息扫读速度。

### Figma UI3
重点：把作品放回中心；固定且可预测的工具区域；在“更简洁”与“专业用户效率”之间保持平衡；可见标签与无障碍不能为了极简被牺牲。

### Raycast 2.0
重点：专业工具要有原生感、速度感和熟悉感；半透明/材质效果应服务层级而不是装饰。

### Apple WWDC26 / HIG
重点：内容优先、跨尺寸适配、可读性、清楚命名、熟悉的交互和可访问性。

### Material 3 Expressive
重点：表达力不是“更花”，而是有目的地用尺度、形状、颜色、动效和容器突出关键动作；大触控目标和高对比度可以同时提高现代感和可用性。

## FloraLab 采用的方向

- 保留 Atelier 的暖纸张、深梅紫、灰绿和编辑杂志气质，不改成通用 SaaS。
- 作品、Blueprint 和材料内容优先；导航更安静、结构更一致。
- 手机关键触控目标至少约 40–44px。
- 小号文本提高对比度，焦点状态可见。
- 顶部导航只使用很轻的半透明/模糊，作为层级提示，不做大面积 Liquid Glass。
- 关键动作在尺度和边框上更明确，次要动作退后。
- 结构图与视觉参考图职责分开：一个表达施工，一个表达氛围。
- 品牌图标简化成可在 16/32px 识别的植物 F 字标。

## 明确不采用

- 不做大面积玻璃、霓虹、渐变和漂浮卡片。
- 不为了“前沿”把专业工具做成高动效展示页。
- 不隐藏重要标签只留下难懂图标。
- 不用大量圆角卡片把信息切碎。
