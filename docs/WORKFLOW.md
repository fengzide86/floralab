# FloraLab 使用流程

## 1. 创作

打开 ChatGPT Project「FloraLab｜花艺创作空间」，自然描述想法，也可以上传参考图、现有材料照片或旧 `.floralab`。模型根据需求自主决定是直接给判断、探索方向、分析图片还是制作视觉参考。

## 2. 落地到 Studio

当作品需要进入材料、预算或结构阶段时，在 FloraLab Studio 新建或导入项目。Studio 管理 Recipe、已有材料、用户单价、采购缺口、现实检查、Composition、花器与 Mechanics。

## 3. Blueprint 与制作

在结构页用同一份 Blueprint 编辑 Stem 位置、角度、长度、锁定、镜像、复制和删除；正/左/后/右/俯视同步。进入制作页后按阶段记录已用、剩余和损耗，缺口出现时查看替代建议。

## 4. 跨设备

电脑导出 `作品名.floralab` → 通过微信 / AirDrop / 文件 / 云盘发送到手机 → 手机 Studio 选择“导入作品”。反向操作相同。没有账号同步，也不会把个人作品自动上传到 GitHub。

## 5. 制作中与成品复盘

需要视觉判断时，将最新 `.floralab` 和实拍照片带回 ChatGPT Project。创作空间可以对照当前结构与设计意图给建议；确定后的数量/结构调整再回 Studio 保存为新版本。

## 6. 归档

重要作品建议在关键节点主动导出 `.floralab`。Studio 的 IndexedDB 是便捷自动保存，不替代正式文件归档。
