# FloraLab Studio 1.5.0 — 看见方向

用户在选择构图方向时，以前主要依赖文字；本版让当前作品、六种变化和分支比较直接显示来自 Blueprint 的构图预览。

- 正面、俯视共用同一数据源；同一视角下所有预览使用相同比例。
- 预览调用与实际分支相同的变化算法，遵守材料、颜色、数量、结构等已有锁定；只有点击生成分支才创建独立作品。
- 圆点/方块表示主体点位和特殊物件，颜色取自材料。它是构图示意，不能替代成品效果图或施工五视图。
- 首页品牌图重做为完整花器和舒展轮廓。亚克力主题牌、照片卡、手写卡片改为专门生成的物件形态图，明确显示 AI 示意与非实物照片标记。
- 修复材料详情裁切、Render 说明叠字、手机首页图过小、分支轮廓文字截断与筛选按钮换行。
- 固定 127 张既有参考照片与归属记录，发布时校验文件 SHA-256；另 3 张 AI 示意单独记录，部署不再为这些条目重新搜图。固定文件与来源不表示所有花材都完成了植物学识别核验。

## 验证

- 发布相关检查 802 项，额外 fast-contract 64 项，总计 866 项通过。
- 材料图审计：130/130 本地资源，含 3 张 AI 示意，远程回退 0。
- 本地 URL UI 检查：143 项，桌面 30 张 / 手机 41 张，浏览器缩放 100%，每张独立检查。修复视觉问题后复查受影响状态。
- 正式部署后使用同一脚本验证版本号及全套页面，再人工逐张复验；最终 commit 和 Actions 状态见长期进度文档及交付记录。
- QA 脚本和截图仍沿用 1.4.1 文件名前缀，报告内版本动态读取 package.json。

## 图像来源与边界

品牌图与三张物件示意由内置 image_gen 生成；提示词见 image-prompts-1.5.0.md。既有照片的原来源、作者、许可与摘要保留在 data/material-photo-sources.json。

本版没有把生成图片嵌入某个用户已锁定的 Recipe，也没有新增云端 AI 服务。成品照片上传与对照仍是下一轮待实现事项，不属于本次交付。
