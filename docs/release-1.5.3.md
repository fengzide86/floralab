# FloraLab 1.5.3：产品路线与代码基础拆分

本次围绕后续产品优化建立可维护的模块边界。完整页面与功能方案见 [产品优化方案](PRODUCT_OPTIMIZATION.md)，源码入口见 [代码结构说明](ARCHITECTURE.md)。F1–F4 为后续计划，本次没有宣称完成新界面、站内生图或照片归档。

## 实际改动

- 从 app.js 抽出施工图、效果图交接、作品与清单、制作与记录四个视图模块；节点选择的状态修正留在控制层。
- Recipe 计算分离到 lib/recipe.js；应用内请求适配器分离到 lib/runtime.js；浏览器目录加载支持失败后再次尝试。
- 浏览器运行时改为递归打包静态 CommonJS 源模块，移除按变量名替换源码的拼接方式；模块正文保持原样。
- 新视图加入 index.html 和离线核心资源；语法检查递归发现新增模块。
- 使用 1.5.2 实际运行时生成固定时间与 UUID 的三类场景输出摘要，保护重构兼容性。

已有作品的材料、数量、结构算法、存储键、IndexedDB 版本和 .floralab/2.0 schema 保持兼容。未对用户数据执行批量迁移。
