# FloraLab Studio 1.6.0

这一版将分散的功能组织成能够接续的作品流程：从一句想法开始，比较方向并选定制作方案，核对采购与摆放，记录实耗，最后保留效果图和成品照片。

## 已实现

- 首页显示最近作品、照片封面、阶段与全部本机作品；支持按名称和阶段筛选。
- 新建首屏输入想法即可生成；预算与更多条件可选。明确排除花材、目录材料的数字数量和颜色优先识别，冲突直接提示。原文与识别结果留在总览中。
- 四个任务区串起八个原有工作页。方向变化先预览，保存时另建方案；选为制作方案后默认锁定材料、颜色、数量与主要结构。
- 参考图、效果图、成品照片回到作品；可备注、设为封面、查看大图和移出当前版本。材料或点位变化后旧效果图提示核对；成品页并排比较最近效果图与真实成品。
- 材料清单支持替换材料或颜色，保留数量与点位，重新检查现实条件；已有数量重置待核对。价格留空表示待询价，区分参考价与填写价；采购清单可复制及打印。
- 施工图提供点位选择列表、位置文字和可展开的精细参数；手机上保持图与编辑区可同时查看。
- 动手前可勾选工具、材料和供水准备；记录用量与损耗，允许报告超用缺口并撤销上一次用料记录；进度和勾选可重新打开。
- 修改前快照可预览后恢复；恢复前的状态继续保留。导入验证通过后另建作品；设计文件可以携带图片。
- IndexedDB 升级保留旧作品；事务失败不会留下半份作品或孤立图片，保存失败显示明确状态。

## 验证与部署

本地发布测试、50 个 JS 文件语法检查、134 项桌面/手机流程检查（85 张逐页截图）、11 项存储故障检查通过。正式交付以 GitHub main、该提交对应的 Actions 和部署后同套页面复验结果为准；最终 commit 与线上验收记录附在交付文件中。

测试使用独立浏览器数据，不修改用户已有作品。上传测试图明确标注 QA TEST，只用于验收，不作为成品示例发布。

## 使用边界

作品和图片保存在当前浏览器；换设备应导出“设计与图片”。本版不提供云端同步。效果图仍通过创作空间生成，再添加回作品；网页不声称已具备站内生图。文字识别是可核对的有限规则，复杂结构、未收录材料和完整语义理解仍需要人工判断。生成照片不能保证逐枝可数，制作事实继续以材料清单和施工结构为准。

跨作品采购、商业提案管理、任意自定义材料、多人协作不属于本次上线范围。市场对比与后续方向保留在 PRODUCT_OPTIMIZATION.md。
