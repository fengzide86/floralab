# FloraLab Studio 1.6.1

修复手机新建作品填写后点击按钮不能进入下一页的问题。用户实际页面仍是旧版 Create 表单，但 app.js 已从网络更新，访问不存在的 useExample / intentError 元素时抛错。此前全新浏览器验收没有覆盖这种老用户升级状态。

## 修复

- 构建时为 index.html 引用的全部脚本与样式写入统一版本参数；旧 Service Worker 尚未更新时，也不会命中上一版无版本号的页面模块缓存。
- Service Worker 预缓存相同版本地址，所有 JavaScript / CSS 都采用网络优先；目录读取也使用版本地址，并预缓存以支持离线。
- 不清空 IndexedDB、localStorage 或用户作品来解决升级问题。
- 制作最后一步的底部按钮与顶部一致，均可进入成品记录。
- 正式地址导航等待独立于控件等待，允许慢网络完成加载，功能断言保持不变。

## 回归

qa/navigation_upgrade.py 使用 main 46013d7 的真实旧表单和 Service Worker 文件，在独立浏览器数据中先重现旧缓存与新逻辑混用的错误，再保持旧 Worker 控制页面验证新版本入口。覆盖桌面与手机的新建、方案对比、选定制作、材料详情返回、完整制作步骤、末步进入成品、已有作品保留及新 Worker 激活后的离线新建，共 24 项检查。

发布前执行完整 Release、现有 134 项界面流程检查、存储检查及新增升级回归。GitHub 部署前运行升级回归，部署后对正式地址运行界面与存储验收，最终提交和正式验收结果记录在交付记录与长期进度文档。

当前已打开的旧页面需要刷新一次才能加载新入口；无需清理浏览器数据。刷新前尚未提交的文字应保留，不能把清空缓存或丢弃草稿当成修复。
