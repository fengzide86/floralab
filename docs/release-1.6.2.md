# FloraLab Studio 1.6.2

手机拖动花材时，浏览器滚动手势取消了拖动，位置无法保存；密集点位还会被后绘制的透明命中区域抢选。本版将手势处理拆到 structure 控制器，在 SVG 层声明触摸行为，按屏幕上最近的花头选择点位，完整处理结束、取消和捕获丢失。拖动预览同步枝线与编号，持久化失败不覆盖当前作品。

新增 1 / 5 cm 的六向空间调整、明确的点位锁定状态、数量变化确认、精细调整面板状态保留；手机放大施工图并取消遮住编辑区的图形吸顶。

增加整个项目的使用说明：解释创作空间、Studio 和 .floralab 如何交接，覆盖新建、方向选择、采购、效果图、制作、复盘、导出与恢复。桌面导航及手机菜单均可打开，施工图有直达对应章节的入口。独立阅读版见 [项目使用说明](USER_GUIDE.md)。

新增真实鼠标与触摸回归，验证五视图方向、隐藏轴不变、锁定、取消手势、数值修改、数量保护、帮助保留未提交表单及刷新后几何保留。旧缓存升级检查继续作为发布门禁；最终部署结果记录在交付记录及 Drive 长期进度文档中。
