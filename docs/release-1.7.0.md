# FloraLab Studio 1.7.0

本次优化围绕手机操作、页面接续和保存可靠性。

## 界面与使用

- 首页、创作表单和作品工作区统一墨绿主按钮、奶油卡面、间距、圆角与导航层级。
- 手机实际用料改为每种材料一张记录卡，已用与损耗分别使用「− 数量 ＋」控件；窄屏自动纵向排列。
- 创作表单自动保留一份本机草稿，首页可继续；另起想法须确认后清除。成功保存生成的作品才清理草稿。
- 浏览器后退、前进、刷新可接回原作品工作区，材料详情也可以返回列表。地址只定位当前设备上的作品，不能代替导出文件。
- 项目使用说明同步到网页菜单和 [完整指南](USER_GUIDE.md)。

## 保存与代码

- 页面切换只保存导航位置，不再写回整份旧作品。
- IndexedDB 同一事务内校验本页读过的作品基线，阻止旧标签覆盖其他标签的新修改；冲突候选可以导出后再重新打开最新作品。
- 成品页“标记作品已完成”同时保存当前填写的耗时、问题和备注。
- 作品修改在提交成功后更新页面状态，保存失败不把候选当作已保存结果。
- 独立草稿、导航模块各自管理存储和浏览器历史。材料库源码由七段拼接整理为 browser/library.js，保持生成文件边界。
- 沿用当前作品格式和材料、图片、结构事实，不迁移或清空用户作品。

## 使用边界

作品、图片和草稿保存在当前浏览器。没有新增账号云同步、远端 AI 或自动跨设备分享。换设备、清理浏览器或存储报错前，应导出设计与图片；草稿保存失败时先复制文字。
