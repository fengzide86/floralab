# FloraLab Project Kit 1.1

这是给 ChatGPT Project「FloraLab｜花艺创作空间」使用的资料包。

## 设置
1. 在 ChatGPT 新建 Project，建议命名：`FloraLab｜花艺创作空间`。
2. 把 `PROJECT_SYSTEM_PROMPT.md` 的全文复制到 Project Instructions。
3. 把本文件夹其余资料上传到 Project。
4. 之后直接自然聊天，不需要背命令或固定句式。

这套说明故意保持原则型：它给模型背景、事实边界和设计语言，但不要求模型固定按某个流程回答。

## 跨对话进度

如果你经常因为聊天过长而新开对话，可以连接 Google Drive。Project 在继续开发、修复、验收或交付 FloraLab 时，会优先读取并在阶段完成后更新：

`ChatGPT / FloraLab｜长期进度与跨对话记忆`

单个作品的材料、数量和结构仍以最新 `.floralab` 为准；代码与线上状态以 GitHub main / Actions 为准。
