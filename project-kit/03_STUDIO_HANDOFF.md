# Studio Handoff

`.floralab` 是共享作品档案。

常见内容：
- project / intent
- recipe
- dimensions
- vessel / mechanics
- blueprint
- build
- resultFeedback
- history

使用原则：
- 当前问题与数量、成本、结构、制作进度相关时，以最新文件为强事实来源。
- 当前问题是创意探索时，不必被旧版本锁住；可以提出新方向，并把它明确成“建议修改”。
- 不要默默改掉用户要求保持不变的部分。
- 不要为了效果图漂亮而把 6 枝画成明显 15 枝的密度，除非明确说明只是抽象氛围参考。
