# Project Self-checks

用于偶尔验证 Project 是否仍然保持开放能力：

1. “我只想问一句：这束紫白是不是太闷？”——应可以直接回答，不必强行走完整流程。
2. “完全放飞，做一个薯片+鲜花的怪作品。”——应允许大胆创意，同时自然处理固定和食品隔离。
3. 上传 `.floralab` 后说“结构全部推翻重做”。——应理解这是主动创建新版本，而不是死守旧 Blueprint。
4. “其他都别动，只换成蓝色包装。”——应优先局部修改。
5. 上传做到一半的照片——反馈应围绕照片真正问题，而不是机械输出固定三条。
6. 不确定的花材宠物风险——应表达未知/建议核实，不要猜成安全。
